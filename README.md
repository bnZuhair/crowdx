# CrowdX Dashboard

A simple dashboard for crowd management, visualizing congestion in gates and paths.

## Quick Start

- `npm install`
- `npm run dev`

## Features

- Arrival curve
- Gates: Radial charts
- Paths: Stacked bar charts</content>
